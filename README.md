# SmartCart AI — Business Plan Trailblazers 3.0 Prototype

## Files
- `index.html` — home page, product catalogue, rule-based recommendation demo, project and business-plan snapshot.
- `style.css` — shared responsive styling for the existing purple design, home page and dashboard.
- `script.js` — cart, demo checkout, product filtering, rule-based recommendations and local-browser dashboard calculations.
- `cart.html` — cart and simulated checkout; no payment is processed.
- `admin-login.html` — existing college-demo login page (left unchanged).
- `admin.html` — dashboard separating local demo activity from the illustrative Year-1 business-plan forecast.

## Demo admin login
The existing demo password and login logic have been preserved. The login check is client-side only and is not secure authentication. Do not use it to protect real business data.

## Business-plan assumptions shown
- Startup budget: ₹6.00L
- Year-1 users: 50,000 registered; 20,000 active; 2,000 paid
- Premium revenue: ₹11.88L
- Affiliate revenue example: ₹1.80L (based on the proposal's assumptions)
- Brand partnership assumption: ₹2.00L
- Total illustrative revenue: ₹15.68L
- Operating expenses: ₹14.00L
- Operating surplus: ₹1.68L; operating margin: 10.7%
- Illustrative CAC proxy: ₹600 per paid customer

These are projections from the submitted business plan, not actual revenue or validated demand. Dashboard prototype order records are stored in this browser's localStorage and are not shared between devices. Demo order value is not SmartCart company revenue. The cart's 18% GST setting is illustrative only. Affiliate equivalent displayed in the demo is a mathematical estimate, not tracked or confirmed commission.

The recommendation feature uses predefined rules; it is not connected to a trained AI model. Amazon links should be checked in the Associates account before public promotion.
