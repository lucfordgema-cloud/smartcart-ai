# SmartCart AI — College Project Prototype

## Files
- `index.html` — homepage, product catalogue, recommendations, project overview, affiliate disclosure
- `style.css` — styling and responsive layout
- `script.js` — cart, demo checkout, rule-based recommendations, local browser order storage, dashboard calculations
- `cart.html` — cart and demo checkout
- `admin-login.html` — demo admin login
- `admin.html` — dashboard and order summary

## Run locally
Open `index.html` in a modern browser. For best results, use a simple local static server or GitHub Pages.

## Important project limitations
- The recommendation flow is rule-based and should be presented as a prototype, not as a trained AI model.
- Checkout is a simulation and does not process payments or create real orders with a seller.
- GST, cost and commission values are illustrative assumptions and should be explained as such in the presentation.
- Amazon affiliate links should be checked in the owner's Associates account before public promotion; do not promise commission until tracking is verified.
